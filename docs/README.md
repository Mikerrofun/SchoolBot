# Class Homework Bot — документация

Telegram-бот школьного класса: расписание и домашнее задание на три недели
(прошлая / текущая / следующая), с AI-дедупликацией ДЗ через OpenRouter.

Стек: **Next.js 16 (App Router) + TypeScript + Prisma ORM + PostgreSQL + grammY**.

## Суть работы в двух словах

1. **Расписание привязано к конкретным датам.** Окно «прошлая / текущая /
   следующая неделя» не хранится в БД — оно вычисляется от текущей даты
   (`src/lib/weeks.ts`). Поэтому окно «переползает» само, без каких-либо
   ночных джобов, а история никогда не удаляется.
2. **ДЗ — 1:1 к уроку.** Урок уникален парой `(date, lessonNumber)`, у урока
   максимум одна запись ДЗ. При добавлении нового текста AI решает: это то же
   задание (оставить или заменить более точной формулировкой) или другое
   (заменить). Если AI недоступен — новый текст просто сохраняется, бот не
   ломается.
3. **Бот живёт на webhook.** Telegram шлёт обновления на
   `POST /api/telegram/webhook`, grammY обрабатывает их через
   `webhookCallback`. Никакого polling, никакого отдельного процесса.
