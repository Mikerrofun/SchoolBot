# Руководство пользователя SchoolBot

Как пользоваться ботом класса: смотреть расписание и домашние задания, записывать новое ДЗ и «Дополнительно», а для админов — как подтверждать записи.

## Начало работы

1. Найдите бота в Telegram по ссылке, которую дал классный руководитель, и нажмите **Start** (или отправьте `/start`).
2. Бот приветствует и показывает **главное меню** — четыре кнопки под полем ввода:

   ```
   📅 Расписание
   📝 Домашнее задание
   ✏️ Добавить ДЗ
   📌 Дополнительно
   ```

3. Кнопка «« Меню» (и её варианты «« Недели», «« Дни») всегда возвращает на шаг назад. Заблудились — жмите «Меню».

## 📅 Расписание

Показывает расписание **текущей недели** целиком, одним сообщением: день и дата, под ними пронумерованные уроки.

- Расписание берётся из конфига бота — оно одинаково каждую неделю и меняется только при смене полугодья.
- Если у предмета две группы (например, английский), в расписании он один — группы появляются только при записи ДЗ.

## 📝 Домашнее задание (просмотр)

1. Выберите неделю: **Прошлая / Текущая / Следующая**.
2. Выберите день: **Пн–Пт**.
3. Бот пришлёт всё ДЗ дня **одним сообщением**: по каждому уроку предмет и текст задания. Пустые уроки помечены «—».

В конце сообщения — строка «📌 Дополнительно» с записью за этот день.

## ✏️ Добавить ДЗ

1. Выберите неделю (можно записывать ДЗ и на следующую неделю).
2. Выберите день.
3. Выберите урок кнопкой. Для предметов с двумя группами кнопок две — например, «6. Английский язык (Веренич)» и «6. Английский язык (не Веренич)». Выбирайте свою группу.
4. Отправьте текст ДЗ **одним сообщением**.

Что дальше происходит с записью:

| Ответ бота | Что это значит |
|---|---|
| ✅ ДЗ записано | Задание новое, сохранено сразу |
| ✅ ДЗ обновлено (AI улучшил формулировку) | Это то же задание, что и на прошлой неделе, но сформулировано точнее — бот заменил текст |
| ℹ️ Такое ДЗ уже записано — оставил как есть | Точное повторение прошлого ДЗ, ничего не менялось |
| ⏳ ДЗ отличается от прошлого и отправлено админу на подтверждение | Похоже на другое задание — ждёт проверки админом |
| ⚠️ AI-проверка временно недоступна — ДЗ отправлено админу на ручную проверку | Проверка не сработала — ждёт проверки админом |

Записи «на подтверждении» класс не видит, пока админ их не одобрит. Когда админ решит, вам придёт уведомление: «✅ Твоё ДЗ подтверждено» или «❌ Твоё ДЗ отклонено админом — осталось прежнее ДЗ».

## 📌 Дополнительно

Отдельная запись на день (не привязана к уроку): кружки, события, напоминания.

**Посмотреть:** «📌 Дополнительно» в главном меню → неделя → бот пришлёт всю неделю одним сообщением: «Пн: текст», пустые дни — «—».

**Записать:** при выборе дня в потоках ДЗ есть кнопка «✏️ Дополнительно» → выберите день → отправьте текст одним сообщением. Запись сохраняется сразу; если AI-проверка недоступна, запись уходит админу на ручную проверку.

## Для админов

Админы задаются переменной `ADMIN_TELEGRAM_IDS` (ID через запятую). Что видит админ:

- **Уведомления на проверку.** Когда чья-то запись уходит на подтверждение, админам приходит сообщение: причина (новое ДЗ или AI недоступен), автор, предмет и день, прошлое и новое ДЗ. Под сообщением — inline-кнопки **✅ Подтвердить** и **❌ Отклонить**.
- **Подтвердить** — запись публикуется, автор получает уведомление.
- **Отклонить** — остаётся прежнее ДЗ (или ничего), автор получает уведомление.
- Подтвердить может только админ: остальные видят «Подтвердить может только админ».
- **Просмотр с pending.** В сообщении дня админ дополнительно видит текст, ожидающий подтверждения, с пометкой «⏳ на подтверждении:».

## Частые вопросы

**Бот не отвечает.** Бот работает через webhook — проверьте, что пишете правильному боту, и попробуйте `/start`.

**Записал ДЗ, а класс его не видит.** Запись ушла на подтверждение админу — она появится после одобрения.

**Отправил текст по частям.** ДЗ принимается одним сообщением. Отправьте весь текст заново одним сообщением — бот заменит/обновит запись.

**Ошибся при записи.** Запишите ДЗ заново тем же путём: новая отправка по тому же уроку заменяет текст (возможно, после проверки админом).

**Почему нельзя писать ДЗ на субботу?** Учебная неделя — понедельник–пятница, остальные дни бот не показывает.
